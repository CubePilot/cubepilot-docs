# CUBENANO™

The CUBENANO™ is an ultra-miniaturized hardware platform that enables the development, creation, testing, and refinement of onboard or external components. Key functions include the following:

* Can function as a flight controller. The onboard processors can handle real-time sensor data from the altitude and guidance sensors, run flight control algorithms, and coordinate movements.
* Serves as a high-performance computer hardware featuring onboard sensors and software, which can directly interface with communication modules via its extensive UART and CAN FD communication peripherals.
* Broadcasts information about UAVs in flight.
