# CUBENANO™ Telecommunication Service

CUBENANO™ provides telecommunication and data-transmission services through the CUBENANO™ hardware and supported firmware. This service enables wireless transmission of UAV identification and related telemetry information from unmanned aircraft to ground-based receivers, applications, and monitoring systems.

Using its integrated Bluetooth module, CUBENANO™ continuously broadcasts identification and telemetry data from the unmanned aircraft to CubePilot-operated cloud servers. This wireless data transmission forms the core of the CUBENANO™ telecommunication service.
